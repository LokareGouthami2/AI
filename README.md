# WriteAI 2.0

**Understand. Edit. Learn. Create.**

AI-powered document intelligence platform: upload educational documents, turn them into
structured, **fully editable** study notes, study them (flashcards, quizzes, Ask Your
Document), and render the edited result as a handwritten-style PDF.

> **Status:** design phase. The full system design — architecture, folder structure,
> technology choices, database schema, AI/ML and RAG pipelines, editor architecture,
> editor-to-PDF data flow, API, dataset strategy, phases, testing, risks and security —
> is in [`docs/design.md`](docs/design.md). Implementation starts with Phase 1.
