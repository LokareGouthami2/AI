The handwriting fonts are the Latin subsets published in the `@fontsource/*` npm
packages, converted from WOFF to TTF with fontTools (no glyph changes). DejaVu
Sans is used only as a fallback for characters the handwriting font lacks
(maths symbols, arrows, superscripts).
